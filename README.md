Maison Glow ✨

A Luxury Beauty Salon Website

Maison Glow is a modern, elegant and responsive beauty salon website concept based in Kumba, Cameroon. It showcases a luxury beauty experience through a cinematic black-and-gold design.

🌐 Live Demo

"Visit Maison Glow" (https://maison-glow-beauty.netlify.app/)

🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, responsive layouts and animations
- JavaScript – Interactive functionality
- Formspree – Booking form submissions
- WhatsApp – Appointment enquiries
- Netlify – Website deployment

✨ Features

- Luxury black-and-gold visual design
- Responsive navigation menu
- Animated hero section
- About section
- Eight beauty service categories
- Responsive service gallery
- Online appointment request form
- WhatsApp booking integration
- Contact information
- Custom SVG favicon
- Basic SEO configuration and XML sitemap

💅 Services Featured

- Hair Styling
- Nail Art
- Makeup
- Lash Extensions
- Facials
- Wigs & Extensions
- Braids
- Pedicure

📱 Responsive Design

Designed to provide a smooth browsing experience across desktop, tablet and mobile devices.

🎯 Project Purpose

This project demonstrates how HTML, CSS and vanilla JavaScript can be used to build an elegant, functional and responsive website without relying on a frontend framework.

The visual direction was inspired by the cinematic luxury aesthetic of VividSites Cortex.
